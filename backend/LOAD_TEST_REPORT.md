### Comparison against the eval harness baseline

`EVAL_REPORT.md`'s most recent single-request average total latency: **2132ms**. This is the closest existing artifact to a "Phase 6 baseline" — no separate stored Phase 6 number exists, so this is the most honest comparison point available, called out explicitly rather than assumed.

Cold-pass P99 (4507ms) vs. that single-request baseline: +2375ms higher. Expected and explained: the eval baseline is one request at a time with no contention; the cold pass runs 50 concurrent cache-miss requests sharing this project's single global Voyage rate-limit queue (`services/voyage/rateLimiter.ts`) and, likely, Anthropic's own account-level concurrency limits — both serialize work under concurrent load in a way a single sequential eval request never encounters. The warm pass's P99 (24ms) is the more informative comparison for "does caching help under load," since it isolates the app's own overhead from those external rate limits.
